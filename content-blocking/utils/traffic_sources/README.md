## utils/traffic_sources

Used to store traffic backups and sources.

#### Folder content:

Files:
- ``./traffic_backup.zip`` -- Contains the stored traffic data that was used during the evaluation described in the thesis. Consists of  data from 937 pages.
- ``./traffic_sources.csv`` -- List of top 1000 visited webpages in the Czech Republic. Obtained from https://dataforseo.com/free-seo-stats/top-1000-websites
