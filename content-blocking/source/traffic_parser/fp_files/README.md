## source/traffic_parser/fp_files

Contains configuration files which specify how the fingerprinting logs should be parsed. 

The files were downloaded from the [JShelter repository](https://pagure.io/JShelter/webextension/blob/main/f/common/fp_config).

#### Folder contents:

Files:
- ``./groups.json`` -- Specification of groups that the fingerprinting calls should be divided into
- ``./wrappers.json`` -- Specification of what group each logged API belongs to
