## addons/firefox

Contains extensions for the Firefox browser.

#### Folder contents:

Files:
- ``./adblock_plus_4_15_0.xpi`` -- Adblock Plus version 4.15.0
- ``./firefox_resource_logger.xpi`` -- Custom Firefox Resource logger extension to log succesfull requests
- ``./ghostery_10_4_25.xpi`` -- Ghostery version 10.4.25
- ``./privacy_badger_2025_1_29.xpi`` -- Privacy Badger version 2025.1.29
- ``./ublock_origin_1_62_0.xpi`` -- uBlock Origin version 1.62
