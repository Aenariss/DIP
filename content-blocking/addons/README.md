## addons/

Folder where the addons to be tested are located. Also contains utility addons such as JShelter to be used during traffic logging for fingerprinting logs and firefox_resource_logger to log blocking results in Firefox.

#### Folder contents:

Subfolders:
- ``./chrome/`` -- Contains Chrome addons in ``.crx`` format
- ``./firefox/`` -- Contains Firefox addons in ``.xpi`` format
- ``./firefox_resource_logger/`` -- Source code of the custom Firefox resource logger extension
